# Master the Pixel

Turn a photo or illustration into a bead pattern you can plan, check, and make.

[Create a Perler bead pattern from an image](https://www.masterthepixel.com/create)

![Cat sample showing source photo, bead preview, grid dimensions, and palette controls](./product.png)

## Choose the details worth keeping

A small grid can lose eyes and thin outlines. A large grid needs more beads and more time. Start with a clear subject and a simple background, then compare the preview at different grid sizes.

- Adjust grid dimensions and the number of colors.
- Choose a bead palette, including MARD, Perler, and Hama options.
- Inspect the pattern before exporting the chart and material quantities.

## A practical workflow

1. Upload an image or try a built-in sample.
2. Choose a grid size that fits the intended project.
3. Reduce colors while checking the face, outlines, and small details.
4. Review the chart and bead counts before preparing materials.

The screenshot uses the product's built-in cat sample. Screen colors and community palette approximations do not replace comparison with physical beads.
